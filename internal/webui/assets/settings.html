After download

The command runs only when a download completes, with the torrent details in the environment. The move runs first: the command finds the final folder in GX_PATH. A torrent that cannot be moved keeps its old folder and the command is told so.

Series and movies

The public TVmaze API needs no key. It tells gx-torrent which episodes exist and when they aired, so a series is not limited to what the feeds happened to show. Turn it off to keep the title on this machine only.

Media server (DLNA)

Any number of folders, one per line: each one appears to the players as a browsable folder beside the torrents. Add folder… appends the chosen folder to the list; Download folder adds the one configured above. To remove one, delete its line.

Window and limits for each day of the week
DayModeStartEndDownload (KiB/s)Upload (KiB/s)

Every day has its own window and limits (0 = unlimited). The mode decides: Off (no window), Limit (the values apply inside the window) or Auto (no cap, the auto-speed measures the line there). Outside the window, the global limits above apply. A window may cross midnight: it then belongs to the day it starts on (Friday 23:00–07:00 covers Saturday morning too).

Seeding limits
Automatic speed (measures the line)

When the line queues, the round-trip latency rises: automatic speed lowers download and upload until it is responsive, then raises them again. A manual limit above stays the ceiling; 0 in a maximum lets it discover that direction.

Archive database

Everything the feeds found is kept in the archive database. Delete the old items to free space, then optimize to give the freed space back to the filesystem.

Categories

A category can have its own folder. When a torrent is assigned to it with automatic management on, the torrent moves to that folder; with a category created from the torrent dialog the folder starts empty, so set it here.

Quality profiles

A profile is a named set of accepted resolutions. A title can choose one instead of the plain quality field; the cutoff is the quality at which upgrades stop (empty = no upgrades).
